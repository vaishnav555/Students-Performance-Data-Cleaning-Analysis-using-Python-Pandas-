# Students-Performance-Data-Cleaning-Analysis-using-Python-Pandas-
This project focuses on cleaning, transforming, and preparing a Students Performance dataset using Python and the Pandas library.

-- Project Objective

To understand the structure and quality of raw student performance data
To identify and handle missing values and duplicate records
To perform data type conversions for accurate calculations
To create meaningful new features for better insights
To export a clean, analysis-ready dataset

-- Data Cleaning & Preparation Steps

Loaded the dataset into Jupyter Notebook using Pandas to ensure reproducibility
Performed initial data inspection using .head() and .info()
Identified missing values using .isnull().sum()
Cleaned missing data using median for numeric columns and mode for categorical columns
Removed duplicate records and validated row counts before and after cleaning
Converted data types to appropriate formats for correct analysis
Created new features such as Average Score and Performance Level
Exported the final cleaned dataset as cleaned_data.csv for future use

-- Key Outcomes

Improved data quality and consistency
Reduced dependency on manual Excel cleaning
Created an analysis-ready dataset suitable for reporting or machine learning
Demonstrated real-world data cleaning and transformation skills

-- Skills Gained

Data cleaning and preprocessing using Pandas
Handling missing values and duplicates
Feature engineering and data transformation
Writing clean, reusable Python code
Understanding real-world data quality issues

-- Conclusion 

This project demonstrates practical data analyst skills by applying Python-based data cleaning techniques to a real-world dataset.
It highlights how Pandas can efficiently handle large datasets,
making the data preparation process faster, more reliable, and scalable compared to traditional Excel-based methods.
